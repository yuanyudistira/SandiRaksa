🛡️ SandiRaksa User Guide

SandiRaksa is a desktop application for protecting sensitive data before sharing with AI services. All processing is done locally on your computer.

🚀 Getting Started

  1. Create a new project via File → New Project
  2. Name your project and select a privacy profile
  3. Add files by drag & drop or click Add Files button
  4. Click Scan All to detect sensitive data
  5. Review findings and choose actions
  6. Click Apply Protection to generate protected files

📁 Managing Projects

Projects help organize files and maintain token consistency across scans.

Creating a Project

  1. Click File → New Project or the + button
  2. Enter a project name
  3. Select an appropriate privacy profile
  4. Click Save
💡 Tip: Use separate projects for different contexts (e.g., project A for HR, project B for finance) to keep tokens isolated.

🔍 Scanning Documents

Scanning detects sensitive data using:

  • Patterns for Indonesian formats (NIK, NPWP, KK, BPJS, phone numbers)
  • Context-based person name detection ("Name:" labels, EMR row patterns, table headers)
  • Smart date of birth detection — distinguishes birth dates from visit/appointment dates
  • Custom Patterns you define yourself (e.g. hospital-specific Medical Record formats)
💡 Automatic Column Detection (Excel/CSV): SandiRaksa analyzes both the header name and sample cell content to recommend which columns contain sensitive data — even when the header is ambiguous.

🧩 Custom Patterns (Global)

Every organization may have its own data formats, such as Medical Record numbers that differ per hospital. You can define your own patterns that apply to all projects.

How to Create Custom Patterns

  1. Open Settings → Custom Patterns...
  2. Write patterns as NAME: pattern (one per line)
  3. Click Validate to check, then Save

Example

MEDICAL_RECORD: MR-\d{6}
ROOM: (?:Kamar|Room)\s?\d+
EMPLOYEE_ID: EMP-\d{4,6}

Patterns are written as regular expressions. Lines starting with # are comments.

📝 Note: Custom Patterns are optional. If left empty, standard detection still works normally.

👁️ Reviewing Findings

After scanning, you can review each finding:

  • Protect - Replace with token (default)
  • Ignore - Leave as-is
  • Change Type - Correct the entity type

🔒 Protecting Data

Protection replaces sensitive data with deterministic tokens.

Example

Before: John Doe works at ABC Corp with email john@abc.com
After:  [[PERSON_7F31A2]] works at [[ORG_B4C9E1]] with email [[EMAIL_3D2F1C]]

🔄 Restoring Data

After receiving output from AI, you can restore original data:

  1. Open the Restore menu
  2. Paste text containing tokens
  3. Click Restore
  4. Copy the restored result
⚠️ Important: Restoration only works for tokens from the same project. Do not mix tokens from different projects.

🏷️ Detected Data Types

Indonesian Data

  • ID_NIK - Indonesian National ID Number (16 digits)
  • ID_NPWP - Tax ID Number
  • ID_KK - Family Card Number
  • ID_BPJS - BPJS Health Insurance Number
  • ID_PHONE - Indonesian phone numbers

Personal & International Data

  • PERSON - Person names (context-based detection)
  • DATE_OF_BIRTH - Birth dates (distinguished from visit dates)
  • EMAIL - Email addresses
  • PHONE - General phone numbers
  • ADDRESS - Addresses
  • ORGANIZATION - Organization names
  • CREDIT_CARD - Credit card numbers
  • BANK_ACCOUNT - Bank account numbers
  • IP_ADDRESS - IP addresses

Custom Types

  • Custom Patterns - Any type you define yourself via Settings → Custom Patterns (e.g. MEDICAL_RECORD, ROOM, EMPLOYEE_ID)

🎫 About Tokens

Tokens are placeholders that replace sensitive data. Format: [[TYPE_HEXID]]

Token Characteristics

  • Deterministic - Same value always produces the same token
  • Project-unique - Different tokens across projects
  • Non-guessable - ID uses HMAC, not sequential numbers
  • Reversible - Can be restored to original value
