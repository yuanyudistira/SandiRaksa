# Example Files / File Contoh

Folder ini berisi file mockup untuk testing SandiRaksa. Semua data dalam file ini adalah **data fiktif** dan tidak merepresentasikan orang atau entitas nyata.

## 📁 Daftar File

| File | Format | Deskripsi |
|------|--------|-----------|
| `Data export CSV.csv` | CSV | Data tabular dengan kolom PII (nama, email, telepon, dll) |
| `Data_Pasien_dan_EMR_3000.xlsx` | Excel | Mockup data pasien rumah sakit dengan 3000 baris |
| `Mockup_Data_Sensitif_Pasien.docx` | Word | Dokumen Word berisi data pasien fiktif |
| `Mockup_Data_Sensitif_Pasien 1.pptx` | PowerPoint | Presentasi dengan data sensitif fiktif |
| `Mockup_Data_Sensitif_Pasien.txt` | Text | File teks dengan data PII |

## 🧪 Cara Menggunakan

1. Buka SandiRaksa
2. Buat proyek baru
3. Drag & drop salah satu file contoh ke area drop zone
4. Pilih kolom/data yang ingin diproteksi
5. Klik "Proses" untuk memproteksi
6. Cek hasil di folder output

## 📋 Jenis Data PII dalam File Contoh

- **Nama** - Nama lengkap fiktif
- **NIK** - Nomor Induk Kependudukan (16 digit fiktif)
- **Email** - Alamat email fiktif
- **Telepon** - Nomor telepon Indonesia fiktif
- **Alamat** - Alamat fiktif
- **Tanggal Lahir** - Tanggal fiktif
- **No. Rekam Medis** - Nomor fiktif

## ⚠️ Disclaimer

Semua data dalam file contoh ini adalah **100% fiktif** dan dibuat hanya untuk keperluan demonstrasi dan testing. Tidak ada data nyata yang digunakan.
