SandiRaksa

Lindungi Data Sebelum Berbagi ke AI

Aplikasi desktop yang melindungi data sensitif dalam dokumen sebelum dibagikan ke ChatGPT, Claude, Gemini, dan AI lainnya. 100% lokal, aman, dan reversibel.

⬇️ Download Gratis 📖 Lihat di GitHub

✨ Fitur Utama

🔒

100% Lokal

Semua pemrosesan dilakukan di komputer Anda. Data tidak pernah dikirim ke server manapun.

🔄

Reversibel

Token bisa dikembalikan ke data asli setelah Anda menerima hasil dari AI.

🇮🇩

Dukungan Indonesia

Deteksi NIK, NPWP, No. KK, nomor telepon Indonesia, dan PII lokal lainnya.

📄

Multi-Format

Dukung Excel, CSV, Word, PowerPoint, dan file teks.

🛡️

Enkripsi Kuat

Pemetaan token dilindungi dengan enkripsi AES-256-GCM.

🎯

Konsisten

Data yang sama selalu menghasilkan token yang sama dalam satu proyek.

🚀 Cara Kerja

1

Upload Dokumen

Drag & drop file Excel, CSV, Word, atau PowerPoint ke SandiRaksa.

2

Pilih Data Sensitif

Pilih kolom atau data yang berisi informasi sensitif untuk dilindungi.

3

Proteksi

Data sensitif diganti dengan token unik seperti [[PERSON_A1B2C3]].

4

Bagikan ke AI

Gunakan file terproteksi untuk ChatGPT, Claude, atau AI lainnya dengan aman.
